# PC28 加拿大至尊版 - 宝塔面板 (BT Panel) 极速部署手册

本指南专门针对“404 错误”、“后台打不开”及“采集失败”等常见问题进行了优化。

---

## 1. 核心目录结构 (必读)
为保证安全与功能正常，项目采用了**动静分离**结构：
- `/public` : **Web 根目录**。所有可直接访问的 HTML 和资源都在这里。
- `/public/admin` : **后台管理目录**。访问地址为 `您的域名/admin/index.php`。
- `/src` : 核心逻辑与数据库配置 (禁止 Web 直接访问)。
- `/scripts` : 采集与结算脚本。

## 2. 宝塔面板配置步骤
### 第一步：创建站点
1. 在宝塔“网站”菜单点击“添加站点”。
2. **根目录**：选择项目解压后的文件夹（包含 `public`, `src` 等的那个文件夹）。
3. **运行目录 (最关键)**：
   - 点击站点“设置” -> “网站目录”。
   - 将“运行目录”下拉框选择为 **`/public`**。
   - 点击“保存”。
4. **防跨站攻击 (必须关闭)**：
   - 在同一个“网站目录”设置页，**取消勾选**“防跨站攻击 (open_basedir)”。
   - 否则 PHP 将无法读取 `/src` 目录下的配置文件。

### 第二步：数据库设置
1. 在宝塔“数据库”中创建新数据库。
2. 导入项目根目录下的 **`database/mysql_schema.sql`**。
3. 修改配置文件 `src/Config/database.php`，填入您的数据库信息。

### 第三步：初始化管理员
1. 打开宝塔“终端”或 SSH。
2. 进入项目目录，运行：`php scripts/reset_admin.php`。
3. 默认后台账号：`admin` 密码：`admin123`。

## 3. 解决 404 与采集问题
- **404 报错**：如果您访问 `/admin/` 报 404，请确认您的 Nginx “伪静态”为空，且“运行目录”已设为 `/public`。
- **开奖不显示**：
  - 首次进入可能无数据。请手动运行一次采集：`php scripts/scraper.php`。
  - 确认 `public/api/lottery.php` 返回了 JSON 数据。
- **采集失败**：`scraper.php` 已内置自动模拟逻辑。若 20 秒内源站无响应，会自动生成带正确期号的模拟数据。

## 4. 计划任务 (Cron) 必填项
在宝塔“计划任务”添加以下任务（类型：Shell 脚本）：

1. **自动采集** (每 1 分钟)：
   `php /www/wwwroot/您的站点目录/scripts/scraper.php`
2. **自动结算** (每 1 分钟)：
   `php /www/wwwroot/您的站点目录/scripts/settle.php`
3. **机器人下注** (每 2 分钟, 可选)：
   `php /www/wwwroot/您的站点目录/scripts/bot_betting.php`

---
**提示**：为了极致的用户体验，建议在宝塔 SSL 菜单中申请免费的 Let's Encrypt 证书，开启 HTTPS 访问。
